# @capsule-css/core

Core runtime for [capsule-css](https://github.com/capsule-css/capsule-css) — resolves and invokes the platform binary to compile `.capsule.css` files.

This package is a dependency of bundler plugins (`@capsule-css/vite`, and future Rollup/webpack targets). You do not need to install it directly.

## Install

```bash
npm install -D @capsule-css/vite
```

`@capsule-css/core` is installed automatically as a dependency.
